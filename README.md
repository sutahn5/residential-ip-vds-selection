## 先分清两件事：住宅 IP 与“双ISP”的真实含义

普通德国 VPS 用的是数据中心 IP 段，IP 库里 type 显示 hosting 或 datacenter，TikTok、银行、流媒体风控看一眼 ASN 和 company 类型就能判定为机房出口。住宅 IP 段来自本地家宽运营商，type 为 isp，被识别为家庭用户。丽萨这条线上，第三方用 IPinfo、ipregistry 等数据库复核过，判定为原生住宅 IP，多项脚本检测也没有发现 IP 被标记污染。

关于“双ISP”，一个常见误解是以为买到了两个 IP。所有套餐默认只给 **1 个 IPv4**，多 IP 要单独加购。双 ISP 指的是这个 IP 有两个运营商背书：一种说法是同一个 IP 在两个 ISP 名下都有注册记录，另一种说法是 IP 提供方同时与两家运营商合作以提升冗余。从回程路由能看到多路径的痕迹——电信、联通从 GTT 接入，移动走 Arelion。两种解释并不冲突，合起来就是“一个 IP，两家运营商背书”，纯净度和稳定性比单 ISP 高一档。

还有一条容易买错的线：丽萨的德国产品线有两条。**德国双ISP原生住宅IP VDS** 是住宅属性，面向 TikTok、流媒体、本土账号注册；**德国9929精品网络双栈双原生IP VPS** 是原生 IPv4+IPv6 加三网 9929 优化，IP 是原生 IP 而不是住宅 IP，面向对国内速度敏感的场景。两条线价差很大，冲着“住宅”两个字来的别买错。
